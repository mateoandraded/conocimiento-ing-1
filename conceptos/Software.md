# Software

**En una línea:** código + datos + documentación.

## Definición (Pressman)
> Software is: (1) **instructions** (computer programs) that when executed provide desired features, function, and performance; (2) **data structures** that enable the programs to adequately manipulate information; and (3) **descriptive information** in both hard copy and virtual forms that describes the operation and use of the programs.

## Rol dual
- Para el ingeniero es un **producto** (programas, datos, documentación).
- Para el usuario es un **vehículo / herramienta** para producir otro producto (una orden de compra, una venta): lo que le importa es la **información** resultante.
- El software entrega el producto más importante de nuestra época: **información** (dato → información → conocimiento → sabiduría).

## Buen software
Entrega la funcionalidad y el desempeño requeridos y es **mantenible, confiable (dependable) y usable**.

## Categorías dominantes
WebApps y aplicaciones móviles (el proyecto del curso debe tener componente web + móvil, o solo móvil).

## Se confunde con
- "Software = código". Error: sin datos ni documentación no es software completo.
