# Conocimiento: Ingeniería de Software I (ESPOL, PAO 2026-2)

El contexto completo de la materia y del proyecto CogniSync del Team 1, organizado para que **cualquier IA (Claude, ChatGPT, Gemini, Copilot…) lo lea y sepa qué hacer**: clases, slides en texto, guías, conceptos, especificaciones y rúbricas del proyecto, el SRS y el estado actual.

## Cómo usarlo con tu IA

**Claude Code o Cursor (lo mejor)**
```bash
gh repo clone mateoandraded/conocimiento-ing-1
cd conocimiento-ing-1
claude
```
Claude lee `CLAUDE.md` solo; Cursor, Codex y Copilot leen `AGENTS.md`. Luego pregunta, por ejemplo: «¿qué falta para el proyecto parcial?», o pega la rúbrica de un entregable.

**ChatGPT**
- Opción 1: crea un *Project*, sube `AGENTS.md`, `COURSE_CONTEXT.md`, `PROJECTS.md`, `CLAUDE.md` y la carpeta `clases/`, y pega como instrucciones del proyecto: «Sigue AGENTS.md».
- Opción 2: en *Settings → Connectors*, conecta GitHub y elige este repo.

**Claude.ai (web)**: crea un *Project*, usa *Add content → GitHub* y elige este repo. En las instrucciones del proyecto pon: «Sigue AGENTS.md».

## Qué hay

| Carpeta o archivo | Contenido |
|---|---|
| `AGENTS.md` | Qué hacer según lo que te pidan (empieza aquí) |
| `CLAUDE.md` | Rutinas completas del tutor |
| `COURSE_CONTEXT.md` | Profesor, evaluación, fechas, formato de examen, lo que entra |
| `PROJECTS.md`, `proyecto/` | Estado de CogniSync, historias de usuario, SRS y acta |
| `clases/` | Una nota por clase con transcripción |
| `conceptos/` | Notas atómicas por concepto |
| `material/` | Slides y talleres (PDF) y su texto en `_texto/`, especificaciones y rúbricas del proyecto |
| `guias/`, `referencias/` | Guías de estudio e índice de consulta del SWEBOK |
| `STUDY_STATE.md`, `ERRORS.md` | Progreso de estudio y errores de Mateo (cada uno puede llevar los suyos en su copia) |

**No incluido** (derechos de autor o datos personales): los PDF de los libros, las normas IEEE 830 e ISO/IEC/IEEE 29148, el SWEBOK en PDF (es gratis en computer.org/swebok) y la carta del proyecto firmada por el cliente.
