Unit 1
Course Description
• This course addresses the importance of software engineering,
the development life-cycle of a software product, and the
application of a software development methodology.
▪Specifically, it makes emphasis on planning, management, requirements
analysis and design of a software system of medium complexity.
• Technical and non-technical skills are developed or improved
during the course.
▪Among the technical skills we have: the application of methods and
tools to plan a software development project, the analysis of the needs
of a real customer, and the design of a software system: both
architectural and detailed design.
▪The non-technical skills include teamwork; ethics in the software
engineering profession; and oral and written communication.

Policy on Authorship (Based on ACM)
• Can I use generative AI software tools to prepare my
assignments?
• Yes, the use of such tools is permitted, subject to the
following requirements:
▪That these systems do not plagiarize, misrepresent, or falsify
content in assignment submissions.
▪That the resulting work in its totality is an accurate representation
of the students’ underlying work and intellectual contributions
and is not primarily the result of the tool’s generative capabilities.
▪That the students accept responsibility for the veracity and
correctness of all material in their work, including any computer-
generated material.

Unit 1
Policy on Authorship (Based on ACM)
• If I use generative AI software tools, under what conditions must
I disclose their use?
▪If you are using generative AI software tools such as ChatGPT, Jasper, AI-
Writer, Lex, or other similar tools to generate new content such as text,
images, tables, code, etc. you must disclose their use.
▪If entire sections of a work, including tables, graphs, images, and other
content were generated by one of these tools, you should disclose
which sections and which tools and tool versions you used to generate
those sections by preparing an Appendix or a Supplementary Material
document that describes the use, including but not limited to the
specific tools and versions, the text of the prompts provided as input,
and any post-generation editing (such as rephrasing the generated
text). Students should also note that the amount or type of generated
text allowable may vary depending on the type of the section affected.
38

• If I use generative AI software tools, under what conditions

▪If you are using generative AI software tools to edit and improve

grammar, punctuation, clarity, engagement or to use a basic word
processing system to correct spelling or grammar, it is not
necessary to disclose such usage of these tools in your Work.
